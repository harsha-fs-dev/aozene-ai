# AOZENE 🎙️

### AI-Powered Voice Production Coordination Platform

AOZENE is an AI-powered platform that simplifies voice production coordination by connecting voice artists and production teams through an intelligent voice-driven workflow.

## ✨ Features

* 🎙️ AI-powered voice interaction
* 👤 Voice artist coordination
* 📋 Production workflow management
* ✅ Artist confirmation and status tracking
* 📊 Centralized production dashboard

## 🛠️ Tech Stack

* **Frontend:** React.js, Vite, JavaScript
* **Backend:** Java, Spring Boot, REST APIs
* **AI/Voice:** AssemblyAI
* **Tools:** Git, GitHub, VS Code, IntelliJ IDEA
